# Telegram Copier Bot

Auto-copy messages from source channels to destination channels (without forward tag) and add reactions.

## Features
- 🎯 Button-based admin panel (no typing!)
- ➕ Add channels via forward
- 💫 Custom reaction per channel
- 🔄 Auto copy without "Forwarded" tag
- 📋 Manage channels (toggle/remove)

## Deploy
FadeHost / VPS. Env vars: `TG_API_ID`, `TG_API_HASH`, `BOT_TOKEN`, `SESSION_NAME`, `ADMIN_ID`.
